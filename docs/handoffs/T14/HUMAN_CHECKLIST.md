# BORROWED PIXELS RC human checklist (under 10 minutes)

Machine validation does not replace these human-only checks.

1. On a clean Windows 10 or 11 x64 PC, copy only the three files in `dist/contest` and launch `BorrowedPixels.exe` (1 minute).
2. Confirm the unsigned Defender/SmartScreen prompt, if shown, matches the README notice; record the result without claiming a signed build (1 minute).
3. From TITLE, open OPTIONS; switch KO/EN, volume, REDUCE FLASH, COLOR ASSIST, and WINDOW/BORDERLESS, then return (2 minutes).
4. Start a run; move, fire, reclaim, dash, and make one settlement choice. Confirm firing visibly lends body mass and both ledger totals remain 1,440 (2 minutes).
5. Load the prepared save or use the review route to view one ending, CREDITS, TITLE return, CONTINUE FROM VESSEL, and AUDIT TRACE (2 minutes).
6. Repeat launch-only checks on two additional Windows x64 PCs and record OS/version, launch result, and any warning (2 minutes).

Record Gate 3/4/5 subjective judgments separately. Until a human performs them, their status remains `HUMAN_REVIEW_DEFERRED`.
